    AQUADISC

    SPOTIFY PREMIUM

    Spotify ne donne les titres complets et le réglage du volume qu'à son lecteur officiel, avec un compte Premium. Il faut créer une clé gratuite, une seule fois (2 minutes) :

    1. Ouvre developer.spotify.com/dashboard, connecte-toi avec ton compte Spotify, accepte les conditions puis clique Create app.
    2. Nom : AquaDisc, description au choix. Dans Redirect URIs, colle exactement ceci puis clique Add : http://127.0.0.1:5177/
    3. Coche Web API et Web Playback SDK, accepte et clique Save.
    4. Dans l'app créée, ouvre Settings, copie le Client ID et colle-le ici :

    Spotify te demande d'autoriser AquaDisc, puis te renvoie ici. Aucun mot de passe n'est gardé par le site. Si Spotify affiche « user not registered », ajoute ton e-mail Spotify dans User Management de l'app.
